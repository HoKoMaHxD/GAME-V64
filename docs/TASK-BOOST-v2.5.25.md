# دبل فلوس المهام

الأمر الإداري: /دبل
الخيارات المطلوبة:
- المضاعف: عدد صحيح من 2 إلى 100؛ 2 يعني ×2، و3 يعني ×3، وهكذا.
- المدة: بالدقائق من 1 إلى 10080؛ 60 تعني ساعة.
- الصورة: مرفق PNG أو JPEG أو GIF أو WebP.

مثال: /دبل المضاعف:3 المدة:60 الصورة:banner.png

الصلاحية مثل المزاد: مالك السيرفر أو Administrator أو Manage Guild أو رتبة إدارة البوت المحددة. ينشر البوت إعلانًا عامًا في نفس قناة تنفيذ الأمر ويمنشن الرتبة 1516418133131268187 مرة عند النشر. يحتاج صلاحيات العرض والإرسال والإيمبد وقراءة سجل الرسائل، وأن تكون الرتبة قابلة للمنشن أو يمتلك البوت صلاحية منشن الرتب. تأكيد الأمر للإدارة مخفي.

الإعلان يستخدم هوية الإيمبد الحالية مثل المزاد، بصورة الفعالية ومضاعفها ومدتها وبدايتها ونهايتها ومثال للمكافأة. يتغير إلى انتهى دبل المهام بعد النهاية دون منشن جديد. عند فشل النشر يعاد تلقائيًا؛ سجل الرسائل ومعرف إرسال ثابت يساعدان على استرجاع إعلان سبق إرساله دون تكرار المنشن.

يبدأ الدبل عند حفظ الأمر وينتهي تلقائيًا بعد المدة حتى بعد إعادة التشغيل. لا يمكن إنشاء فعالية ثانية متداخلة. لا إعدادات بيئة جديدة؛ يسجل أمر /دبل عند تشغيل النسخة بالطريقة السابقة.

يشمل الدبل مكافآت إكمال المهام التلقائية: مهام الرسائل والفيلنق واللوكت والصوت والألعاب المحسوبة ضمن المهام. يُحسب المضاعف حسب توقيت إكمال المهمة: البداية مشمولة، والنهاية غير مشمولة. تبقى المكافأة الأساسية للمهمة محفوظة ويُسجل المبلغ المصروف والمضاعف ومعرف الفعالية في سجل الإنجاز. المهام المكتملة سابقًا لا تعاد مكافأتها ولا تُضاعف بأثر رجعي؛ مهام قيد التقدم تستفيد إذا اكتملت خلال المدة.

لا يشمل الحضور الصوتي المنفصل أو الرواتب أو الجوائز أو أرباح الألعاب البنكية أو التحويلات أو إضافات الإدارة اليدوية. إجمالي مكافأة المهمة = المكافأة الأساسية × المضاعف. لا تتكدس فعاليات الدبل.
