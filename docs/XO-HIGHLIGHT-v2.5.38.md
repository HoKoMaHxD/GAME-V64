# علامة الاختفاء
بدل التنبيه النصي بالصف والعمود، تظهر أقدم علامة للاعب صاحب الدور باللون الأحمر عندما يملك ثلاث علامات. تبقى العلامة غير قابلة للضغط لأنها مشغولة. بعد اختيار خانة فارغة تختفي العلامة القديمة ويتغير التمييز لصاحب الدور التالي. لا يوجد تمييز أحمر عند انتهاء القيم؛ يبقى تمييز خط الفوز الحالي.
