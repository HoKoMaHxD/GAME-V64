# إصلاح تعليق أزرار الألعاب — 2.5.47

## الأسباب التي ظهرت في الكود

1. **تحديث قديم يستبدل لوحة أحدث:** مؤقّت الألوان والنرد كان يعدّل الرسالة بصورة مستقلة عن ضغطات اللاعب. إذا تأخّر تحديث المؤقّت ووصل بعد حركة أحدث، يرجع شكل اللوحة وأزرارها إلى رقم دور قديم، بينما قاعدة البيانات تحتفظ بالدور الجديد.
2. **انتظار Discord يحجز بقية الألعاب:** تحدّيات اللاعبين كانت تتحقق من عضوية الخصم عبر Discord داخل القفل المشترك لعمليات الرصيد. طلب بطيء يؤخّر العمليات الأخرى التي تنتظر القفل نفسه.
3. **رسالة بطيئة توقف دورة التحديث:** عمّال تحديث الألعاب كانوا ينتظرون كل رسالة بالتتابع. تأخر رسالة واحدة يؤخّر تحديث بقية الرسائل وإغلاق بطاقات التشابه وإظهار الزر الأخضر.
4. **الأزرار القديمة لا تُصلح نفسها في بعض الألعاب:** رفض رقم الدور القديم لم يكن يعيد اللوحة الصحيحة دائمًا. وفي تشابه والألوان كانت بعض الضغطات القديمة تُتجاهل دون تنبيه واضح.
5. **نسختان للجولة الفردية نفسها:** تكرار أمر الألوان أو النرد كان يستطيع إرسال نفس الجولة في رسالة أخرى ونقل معرّف الرسالة إليها، فتتوقف الرسالة السابقة عن تلقي التحديثات.

هذه أسباب أُعيد إنتاجها محليًا. لا توجد سجلات من سيرفر التشغيل تثبت أن كل شكوى سابقة سببها واحد منها.

## التغييرات

- قفل عرض موحّد لكل جولة بين الأزرار والمؤقّتات؛ الألعاب المختلفة تستطيع التقدم بصورة مستقلة.
- تحديثات خلفية محدودة بأربع رسائل متزامنة لكل مدير ألعاب، مع استمرار دورات المؤقّت أثناء انتظار Discord.
- قراءة أحدث حالة بعد انتظار الشبكة، وتجاوز التحديث إذا كانت النسخة نفسها قد عُرضت بالفعل.
- التحقق من العضوية قبل دخول قفل الرصيد في XO والزر والألغام والأرقام ودوت والألعاب الفردية. فحص الرصيد والدور والصلاحية الزمنية والتسوية المالية يبقى داخل القفل.
- إصلاح لوحة التحدّي عند ضغط زر قديم، مع تنبيه خاص بأن الضغطة لم تُحسب. لا تُعاد حركة قديمة على دور جديد.
- تثبيت الجولة على رسالتها الأصلية. تكرار أمر اللعبة الفردية يعطي رابط الجولة الحالية، والضغط على نسخة قديمة يوجّه إلى الرسالة الأصلية.
- الحفاظ على استعادة ربط الرسالة إذا نجح إرسالها ثم تعذّر حفظ معرّفها؛ أول تفاعل لاحق يستطيع استكمال الربط.
- تقليل كتابات ربط الرسائل المتكررة، وإضافة فهرس لبحث لوحات التحدّيات التي تحتاج تحديثًا.

تبقى نسب الربح والخسارة، الأرصدة، مستويات تشابه ومهل اللعب كما هي. تحتاج ضغطة جديدة بعد تنبيه تحديث اللوحة، وتبقى بطاقتا التشابه المختلفتان معروضتين لمدة ثانيتين.

## التثبيت

1. استبدل ملفات المشروع بهذه النسخة كاملة، بما فيها `src/game-display.js` وملفا الحزم ومجلد `assets`.
2. أبقِ إعدادات البيئة وقاعدة البيانات الحالية. لا تحتاج إلى تصفير الأرصدة أو حذف بيانات الألعاب.
3. أعد النشر على Render كالمعتاد. إصدار الحزمة الجديد هو `2.5.47`، والفهرس الإضافي يُنشأ عند التشغيل.
4. بعد اكتمال التشغيل، جرّب تشابه ودوت والزر والألوان في شات البنك. عند ظهور تنبيه اللوحة المحدّثة، اختر من الأزرار الجديدة.

أوامر الفحص المحلي:

```bash
npm ci
npm run check
npm run test:games
npm test
```

الأمر الأخير ما زال يخرج بحالة فشل بسبب اختبارات النهب السبع المذكورة أعلاه.
