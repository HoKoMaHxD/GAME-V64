# Infinite XO

مرجع القواعد: https://www.infinitytictactoe.com/blog/how-infinity-tic-tac-toe-works

كل تحد جديد بأمر اكس أو /اكس يعمل بنظام ثلاث علامات لكل طرف. توضع العلامة الجديدة في خانة فارغة؛ إذا كان لدى اللاعب ثلاث علامات، تزال الأقدم له في الحركة نفسها قبل فحص الفوز. ثلاث علامات أفقية أو عمودية أو قطرية تفوز. لا يحدث تعادل بسبب امتلاء اللوحة في النظام الجديد. لا يوجد حد حركات مفروض؛ مهلة الدور الحالية تنهي جولة اللاعب الذي لا يختار.

نفس لوحة 3×3 ونفس الألوان وتسميات X/O وتصميم الإمبد. سطر تعريفي وسطر يحدد صف وعمود العلامة التالية للاختفاء، دون تغيير أشكال الأزرار. الصفوف من الأعلى والأعمدة من اليسار. لا يمكن اختيار خانة مشغولة، بما فيها علامتك الأقدم، قبل اختفائها.

يحفظ ترتيب العلامات مع كل حركة ذريًا ضمن سجل القيم. الجولات السابقة دون xoMode تستمر بالنظام التقليدي؛ لم نخمن ترتيب حركاتها. الألعاب الأخرى التي تستخدم البنية المشتركة لا تتغير. المبالغ والحجز والمهل وانتظار التحديات كما هي.

التحقق: 38 اختبارًا محليًا نجحت، تشمل القاعدة الجديدة والإزالة قبل فحص الفوز وحفظ الترتيب والتصميم وصرف المبلغ مرة واحدة، واختبارات النظام القديم للجولات القائمة. فحص صياغة الوحدات المعدلة ناجح. لم يتم اختبار Discord أو قاعدة الإنتاج فعليًا.
