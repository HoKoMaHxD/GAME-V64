# السجل المالي
القناة: 1554179860396642335

يبدأ التسجيل من تشغيل هذه النسخة. كل تعديل محفوظ للرصيد يسجل معه سجل معلق في وثيقة اليوم نفسها، ثم ينقل إلى financial_logs ويرسل إلى القناة خلال دورة تبلغ نحو 15 ثانية (قد يتأخر مع كثرة العمليات).

يشمل المهام والدبل والحضور والراتب والجائزة والنرد والألوان والنهب والحماية والمتجر والمزاد وتحديات الأعضاء والتعديل الإداري وتصفير الرصيد. الحجز والرد يسجلان كحركتين مستقلتين، وتظهر نتيجة تحديات الأعضاء وصافي ربح أو خسارة كل طرف في سجل نتيجة منفصل. الرصيد قبل وبعد هو الرصيد القابل للاستخدام؛ قيمة الحجز ليست خسارة نهائية.

كل رسالة تحتوي العضو والمبلغ والرصيد قبل وبعد والمصدر والتوقيت ومعرف السجل. ملف JSON مرفق يحفظ تفاصيل المكونات والإيصالات ومعرفات العمليات والسياق المتاح. لا يسجل كلمات السر أو التوكنات. لا يعيد إنشاء تاريخ العمليات قبل تثبيت التحديث.

التصفير الشامل ينقل السجلات المعلقة للأرشيف قبل حذف الأيام. يحتفظ الأرشيف بمعرف الرسالة وحالة الإرسال. تعطل شات اللوق لا يلغي العملية المالية؛ تبقى سجلاتها لإعادة المحاولة. منع التكرار يستخدم معرف السجل وnonce وفحص أحدث 100 رسالة؛ لا توجد ضمانة مطلقة لعدم التكرار بعد انقطاع طويل جدًا وفقدان تأكيد الإرسال وخروج الرسالة من آخر 100 رسالة.

الصلاحيات: مشاهدة القناة، إرسال الرسائل، تضمين الروابط، إرفاق الملفات، قراءة سجل الرسائل. يجب أن تكون القناة داخل سيرفر الكلان.

التحقق المحلي: 64 اختبارًا للأوامر والصلاحيات والسجل المالي، و38 اختبارًا للسجل وتسوية اكس نجحت. الفحص الشامل كشف ثلاثة توقعات قديمة لعدد الأوامر، وتم تحديثها وإعادة فحصها بنجاح. لم يتم اختبار Discord فعلي أو MongoDB إنتاجي.
