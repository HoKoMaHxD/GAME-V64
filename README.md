# إعدادات خصم السبام — v2.5.50

استخدم **`/خصم المدة:5 المبلغ:1000`** لضبط مدة السبام على **5 ثوانٍ** وخصم **1000** لكل مخالفة. المدة هي الفترة التي يُحسب خلالها عدد الرسائل من العضو في الشات نفسه؛ يمكن تحديد العدد بخيار الرسائل.

- `المدة`: عدد صحيح بالثواني، من **1 إلى 3600**.
- `المبلغ`: عدد صحيح من **1 إلى 1,000,000**.
- يمكن تغيير خيار واحد فقط، أو كتابة `/خصم` دون خيارات لعرض الإعدادات الحالية.
- الأمر متاح لصلاحيات إدارة البوت الحالية داخل سيرفر الكلان، والرد خاص بمن يستخدمه.
- الإعدادات محفوظة بعد إعادة التشغيل وتطبق فور حفظها على المخالفات الجديدة في شاتي السبام الحاليين. الافتراضي **3 ثوانٍ / 500**.
- المخالفات المحفوظة قبل التغيير تُستكمل وفق المدة والمبلغ المسجلين عند رصدها، ولا يتكرر الخصم.
- الرصيد يتوقف عند **0**؛ إذا كان أقل من مبلغ الخصم يُخصم المتبقي فقط.
- للتحديث: استبدل الملفات وأعد تشغيل البوت؛ يُسجل أمر `/خصم` تلقائيًا. استخدم إعدادات البيئة وقاعدة البيانات الحالية.

3. Build Command: `npm ci --omit=dev`، وStart Command: `npm start`. أعد النشر؛ يظهر الإصدار **2.5.12** في سجل التشغيل.
4. لوحة `/setup` المحفوظة تتحدث تلقائيًا. أعد إرسال `/ترتيبي` أو `- ترتيبي` للرسائل المنشورة يدويًا حتى يظهر زر **توب البنك** بجانب **تنبيه**.

- الرسائل القصيرة والمكررة والإيموجي والمرفقات تُحسب، لكن حدث الرسالة نفسه لا يُحسب مرتين. رسائل البوتات والويبهوك والنظام لا تُحسب. تعديل الرسالة لإضافة منشن أو وسائط لا يمنح إنجازًا جديدًا؛ يُسمح بمعاينة رابط وسائط تتأخر ضمن نافذة الرصد الأصلية.

رسالة `/ترتيبي` تحتوي بالترتيب: **ترتيبي الشخصي — تنبيه — توب البنك**. نشر الرسالة للإدارة، والضغط على الأزرار متاح لأعضاء سيرفر الكلان.

زر **توب البنك** يعرض جميع أصحاب السجلات البنكية، بمن فيهم الرصيد صفر، على صفحات من 10 أعضاء. توجد أزرار **السابق والتالي والتحديث**، ويظهر ترتيب صاحب الطلب ورصيده. التساوي يفصل بمعرف العضو لترتيب ثابت، ويتعدل رقم الصفحة إذا تغير عدد المشاركين بعد الريست. الرد خاص، وكل عضو يتحكم بصفحته وحده.

الأمر **`/توب_البنك`** والعبارة **`توب البنك`** يعرضان القائمة نفسها، ويمكن استخدام الزر من أي روم داخل سيرفر الكلان. أمر `توب` السابق يبقى متاحًا في شات البنك لعرض أعلى عشرة مع الفارق للمركز التالي.

ترتيب الشات يحسب رسائل شات الكلان فقط، وترتيب الفويس يحسب وقت الرومات المفعلة. الرواتب والمشتريات والمكافآت والنهب وحجوزات المزاد لا تغيّر عدادات النشاط. توب البنك يرتب الرصيد المتاح بعد كل الحركات والحجوزات.

## التنبيهات بالخاص

اختيار كل عضو السابق محفوظ؛ التنبيهات مفعلة افتراضيًا. زر **تنبيه** بجانب **ترتيبي الشخصي** يوقف جميع تنبيهات العضو، والضغطة التالية تعيد تفعيلها.

تنبيهات المهام الجديدة:

- اكتمال كل مهمة وصرف مكافأتها، ثم تنبيه عند إكمال كل مهام اليوم.
- قبل التجديد بعشر دقائق عند وجود تقدم ومهام غير مكتملة.
- عند منتصف الليل: ملخص اليوم السابق، عدد المهام غير المكتملة ومكافآته، وإتاحة اليوم الجديد. يُجدول هذا التنبيه للأيام التي بدأ فيها سجل مهام العضو؛ لا تُرسل سلسلة ملخصات لأيام غاب فيها ولم يكن له سجل.

تبقى تنبيهات صرف الراتب وإتاحته، الحصول على الجائزة وإتاحتها، نتائج النهب لكل طرف، شراء/تمديد/انتهاء الحماية، المتجر وتعديل الرصيد والريست، ومراحل المزاد والتجاوز والفوز والإلغاء. تنبيهات القبول والرفض وانتهاء الأربع ساعات القديمة تصبح غير صالحة.

التنبيهات محفوظة وتتحمل إعادة التشغيل، ولا يتكرر الحدث عند إعادة محاولة حفظه. تعطيل التنبيهات أو إغلاق الخاص لا يلغي الإنجاز أو يغيّر الرصيد. قد يتأخر الإرسال قليلًا: الفحص كل 15 ثانية وبحد رسالة واحدة لكل عضو في الدورة لتجنب التكدس.

## الراتب والجوائز وبقية البنك

- الراتب يُطلب كل **ساعة**. إذا كان العضو مبوستًا فعليًا لسيرفر الكلان، تصبح الوظيفة **مدير كبير** والراتب الأساسي عشوائيًا من **2,000 إلى 3,500 $** بدل عضو الكلان؛ ثم تُطبق زيادة الجائزة المحفوظة.
- الجائزة تُطلب كل **ساعتين**، والنقدية **500–2,000 $**. زيادة الراتب بين **50% و70%** لمرة واحدة.
- أُلغيت جائزة تقليل انتظار المهمة مع إلغاء انتظار المهام. أي جائزة سابقة غير مستخدمة من هذا النوع تُستخدم كزيادة راتب **بالنسبة نفسها**، مرة واحدة وبترتيب حصول العضو عليها. السحب الجديد يعطي زيادة راتب باحتمال الثلثين أو نقدًا باحتمال الثلث، مع بقاء احتمال النقد السابق.
- `وقت` يعرض المتبقي للراتب والجائزة والحماية والنهب، وموعد تجديد المهام اليومي. لا يصرف أو يستهلك جائزة ولا ينشئ سجل مهام بمجرد القراءة.
- قواعد النهب والمزادات والحماية وإصلاحات اللغم في المرفق محفوظة. الحماية المشتراة في هذه النسخة **10,000 مقابل 3 ساعات** وتُضاف إلى الوقت السابق. قواعد هذه الميزات لم تُعدّل في تحديث المهام.
- ريست البنك يصفّر الرصيد وحده، وريست الشات والفويس يصفّر عدادات النشاط وحدها؛ لا يعيدان صرف مهمة أُنجزت. الريست الشامل المخصص للعضو يزيل سجله وفق آلية التأكيد الموجودة.

## الإعداد والتشغيل

استخدم عاملًا واحدًا كما في `render.yaml` وقاعدة MongoDB الحالية. Node ضمن المجال في `package.json`. لا توجد مكتبات جديدة. متغيرات الروابط والرتب والرومات المستخدمة:

| المتغير | الغرض |
| --- | --- |
| `DISCORD_BOT_TOKEN` | البوت الرسمي الذي يستقبل أوامر الكلان |
| `OBSERVER_MODE` | `official` أو وضع القارئ الحالي `selfbot` |
| `ARENA_USER_TOKEN` / `ACKNOWLEDGE_SELFBOT_RISK` | إعدادا وضع القارئ الموجودان بالمشروع |
| `MONGODB_URI` / `MONGODB_DB` | قاعدة البيانات |
| `CLAN_GUILD_ID` / `ARENA_GUILD_ID` | سيرفر الأوامر وسيرفر النشاط |
| `CLAN_MEMBER_ROLE_ID` | رتبة عضوية الكلان في أرينا |
| `GENERAL_CHANNEL_ID` / `CLAN_CHAT_CHANNEL_ID` | شاتا مهمتي 50 رسالة؛ يجب اختلافهما |
| `FEELING_CHANNEL_ID` / `LOOK_CHANNEL_ID` | روما المنشور والمنشن، والوسائط والمنشن |
| `CLAN_VOICE_CHANNEL_ID` / `_2` / `_3` | الأول مطلوب، الثاني والثالث اختياريان |
| `ARENA_GAMES_BOT_ID` | الافتراضي `995439183650889888` |
| `ARENA_GAMES_CHANNEL_ID` | الافتراضي `1142961202004234330` |

راجع `.env.example` لبقية الإعدادات الاختيارية. احتفظ بمتغيرات Render، ولا ترفع توكناتك إلى المستودع. يلزم للبوت Message Content وServer Members Intents وفق طريقة العمل الحالية. يحتاج إلى عرض الروم وإرسال الرسائل وتضمين الروابط وقراءة سجل الرسائل لتحديث البطاقات بعد إعادة التشغيل. القارئ يرصد الصوت المستلم ولا يدخل الرومات.

التشغيل المحلي:

```bash
npm ci
npm run check
npm test
npm start
```

`npm run diagnose` لتشخيص الاتصال، و`/حالة_البوت` لفحص القارئ والرومات. التحقق المحلي والحدود موثقان في `VERIFICATION.md`. لم يُجر اتصال بحسابات Discord أو قاعدة الإنتاج أثناء تجهيز التحديث.


## ألعاب البنك — v2.5.15

- `الوان` أو `ألوان` أو `/الوان`: شبكة 9×9 من خمسة ألوان. ابدأ من أعلى اليسار ووسع المساحة المتصلة حتى تصبح الشبكة كلها لونًا واحدًا. نفس اللون الحالي لا يستهلك محاولة.
- عدد المحاولات ليس ثابتًا: يحسب البوت مسار حل فعلي للشبكة ثم يضيف **1 إلى 3 محاولات** عشوائية. البحث محدود لحماية الأداء؛ المسار قابل للتنفيذ لكنه ليس بالضرورة أقصر حل رياضي.
- `نرد` أو `/نرد`: اضغط **رمي النرد**؛ الرقم الأعلى بين رميتك ورمية البوت يفوز، والتعادل لا يغيّر الرصيد.
- لكل لعبة مهلة إكمال **دقيقتين**. انتهاء المهلة بعد ظهور اللعبة يُحسب خسارة. إذا لم يُؤكد إرسالها تُلغى دون خصم. بعد إعادة التشغيل يستكمل البوت الجولات المحفوظة ويعالج المنتهية.
- يختار البوت نسبة صحيحة عشوائية من **5% إلى 10% شاملتين** لكل جولة. الربح يُضاف، والخسارة تُخصم من **الرصيد الحالي وقت النتيجة**، مع تقريب المبلغ إلى الأسفل. لا يغيّر ذلك مكافآت المهام أو سقف الحضور. الرصيد صفر يمنع بدء اللعبة؛ النسب الصغيرة على أرصدة أقل من 20 قد تُقرب إلى صفر.
- لكل لعبة انتظار مستقل **20 دقيقة من بدء الجولة**، محفوظ عبر إعادة التشغيل ومنتصف الليل. إعادة الأمر أثناء الجولة تعرض نفس الجولة ولا تبدأ مقامرة جديدة. أمر `وقت` يعرض الانتظار.
- اللعبتان في شات البنك المحدد؛ الأزرار لصاحب الجولة فقط. الضغط المتكرر أو إعادة إرسال النتيجة لا يكرر المكافأة أو الخصم. تحديث الرصيد ونتيجة الجولة يثبتان في عملية حفظ واحدة.
- تغيير شات البنك أو تصفير البنك يلغي الجولات السابقة دون خصم إضافي. تُحفظ العمليات والمبالغ في سجل اليوم الذي بدأت فيه الجولة.

التحديث: استبدل ملفات المشروع وأعد تشغيله بنفس إعدادات البيئة وقاعدة البيانات. لا يحتاج توكنًا إضافيًا أو تصفير الأرصدة. يسجل أوامر السلاش والفهارس الجديدة عند التشغيل.

## شيخ الكلان ومكافحة السبام
- رتبة `1555677016295219241` في سيرفر الكلان تمنح وظيفة **شيخ الكلان** براتب عشوائي شامل الطرفين **3,000–5,000** كل ساعة. لها الأولوية على مدير كبير، وتطبق زيادة الجائزة المعتادة.
- الشاتان: الكلان `1552646864682221650` وأرينا `1470732708559851673`. افتراضيًا، كل رسالة إضافية من العضو في الشات نفسه بفاصل أقل من 3 ثوانٍ تخصم **500 نقطة**؛ لا يشترط تطابق النص. يمكن تغيير المدة والمبلغ بأمر `/خصم`. أول رسالة والرسائل بفاصل يساوي المدة المحددة أو يتجاوزها لا تخصم. البوتات والويبهوكات والرسائل النظامية مستثناة.
- الحد الأدنى للرصيد **0**. تخصم مخالفة السبام **المبلغ المضبوط بحد أقصى الرصيد المتاح**؛ إذا كان الرصيد أقل من مبلغ العقوبة يُخصم المتبقي فقط، وعند الصفر تُسجّل المخالفة دون خصم إضافي أو دين مؤجل. المخالفات محفوظة ومعرّف الرسالة يمنع الخصم المكرر بعد إعادة التشغيل. تنبيه خاص يوضح الخصم والسبب عبر طابور التنبيهات المعتاد؛ إغلاق الخاص أو تعطيل التنبيهات لا يلغي الخصم.

## تشغيل وإيقاف البوت بالكامل
- `/البنك الحالة: إيقاف`: يوقف كل وظائف البنك والألعاب والاحتساب والسبام وتحديث اللوحات والتنبيهات؛ يبقى أمر التشغيل للإدارة فقط.
- `/البنك الحالة: تشغيل`: يستأنف الوظائف من وقت التشغيل دون احتساب الرسائل أو الصوت أو أقيام النشاط أثناء الإيقاف.
- نفس صلاحيات إدارة البوت الحالية، والحالة محفوظة في قاعدة البيانات وتبقى بعد إعادة تشغيل Render. الأرصدة والتقدم المحفوظ لا يُحذفان.
- الإيقاف لا يقطع اتصال Discord أو قفل قاعدة البيانات اللازمين لتلقي أمر التشغيل. مواعيد انتهاء التحديات والمزادات والانتظار تبقى على وقتها الحقيقي؛ تتوقف معالجتها أثناء الإيقاف وتُعالج عند التشغيل.

## تحسين تكرار ريست توب البنك
- يتجاوز الريست سجلات الأيام التي رصيد المهام والحضور فيها صفر بالفعل؛ لا يعيد قراءتها وتعديلها فرديًا عند تكرار الأمر.
- تُعالج سجلات أعضاء مختلفين بتوازٍ محدود، وتبقى أيام العضو الواحد بالترتيب لحفظ دقة السجل المالي.
- أضيفت مهل للاتصال بقاعدة البيانات والانتظار على اتصالها، حتى لا يبقى طلب قاعدة البيانات معلقًا بلا نهاية. عند تعذر تأكيد الريست، يستمر مسار الاستكمال المحفوظ المعتاد بعد إعادة التشغيل.

## إصلاح تعليق أمر البنك
- حفظ خيار تشغيل/إيقاف يستخدم طابورًا مستقلًا عن عمليات الحساب والريست، فلا ينتظر تعليق عملية أخرى على قراءة قاعدة البيانات.
- يتوقف استقبال العمل الجديد فورًا، وتُحفظ الحالة قبل الرد. إعادة تهيئة رصد الفويس والألعاب تعمل في الخلفية دون انتظار إرسال التنبيهات أو تحديث اللوحات.
- العمليات المالية التي بدأت بالفعل تكمل حفظها الذري؛ لا تُقطع في منتصف تعديل الرصيد.
